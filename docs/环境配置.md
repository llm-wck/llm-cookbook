
## 二、安装本书需要用到的python库



其中，-q 参数，

1、功能概述：用于 静默模式（quiet mode），其主要作用是 减少命令执行时的输出信息。

2、参数详解：`-q` 或 `--quiet`：

- 单个 `-q`：减少输出信息，隐藏详细的安装过程日志，仅显示必要的警告和错误信息。

- 多个 `-q`（如 `-qq`）：进一步降低输出级别，几乎只显示错误信息。

3、使用场景

- 自动化脚本：在编写自动化脚本或持续集成（CI）流程时，使用 `-q` 可以使日志更简洁，便于阅读和排查问题。
- 终端整洁：在需要保持终端输出整洁时，避免大量安装过程中的详细信息干扰。

### python-dotenv

`python-dotenv` 是一个用于管理和加载环境变量的 Python 库。它允许开发者将配置参数存储在 `.env` 文件中，并在应用启动时自动加载这些变量，从而简化配置管理并增强安全性。

一、功能概述

- 加载环境变量：从 `.env` 文件读取键值对并加载到环境中。
- 配置管理：将配置与代码分离，便于不同环境使用不同设置。
- 安全性：避免将敏感信息硬编码在代码中。

二、用法

1、安装

2、创建 `.env` 文件

```sh
# .env
DATABASE_URL=postgres://user:password@localhost:5432/mydb
SECRET_KEY=supersecret
DEBUG=True
```

3、加载环境变量

```python
# app.py
from dotenv import load_dotenv
import os

load_dotenv()  # 加载 .env 文件

database_url = os.getenv('DATABASE_URL')
secret_key = os.getenv('SECRET_KEY')
debug = os.getenv('DEBUG')

print(database_url, secret_key, debug)
```

三、示例

假设 `.env` 文件内容如下：

```sh
API_KEY=abcdef123456
ENV=development
```

在 `app.py` 中加载并使用：

```python
from dotenv import load_dotenv
import os

load_dotenv()

api_key = os.getenv('API_KEY')
environment = os.getenv('ENV')

print(f"API Key: {api_key}")
print(f"Environment: {environment}")
```

输出：

```
API Key: abcdef123456
Environment: development
```

四、注意

- 将 `.env` 添加到 `.gitignore`，防止敏感信息泄露。
- 可以指定 `.env` 文件路径：`load_dotenv(dotenv_path='path/to/.env')`

### openai

一、功能概述

OpenAI Python 库是一个用于与 OpenAI API 交互的官方客户端库。它允许开发者轻松调用 OpenAI 提供的各种人工智能模型，如 GPT（生成文本）、DALL·E（生成图像）和 Codex（代码生成），以集成智能功能到应用程序中。

二、安装

三、用法

1. 设置 API 密钥

首先，需要获取 OpenAI API 密钥，并在代码中进行配置：

```python
import openai

openai.api_key = 'your-api-key'
```

2. 调用 GPT-3 生成文本

以下示例展示如何使用 GPT-3 生成文本：

```python
response = openai.Completion.create(
    engine="text-davinci-003",
    prompt="写一首关于春天的诗。",
    max_tokens=50
)

print(response.choices[0].text.strip())
```

3. 生成图像（DALL·E）

使用 DALL·E 生成图像的示例：

```python
response = openai.Image.create(
    prompt="一只在月光下飞翔的猫",
    n=1,
    size="512x512"
)

image_url = response['data'][0]['url']
print(image_url)
```

四、注意事项

- 安全性：不要将 API 密钥硬编码在代码中，建议使用环境变量或配置文件管理。
- 费用控制：注意 API 调用的费用，合理设置 `max_tokens` 等参数以控制成本。
- 速率限制：遵守 OpenAI 的速率限制，避免因过多请求被暂时封禁。

下面是读取`.env`文件的代码


```python
import os
import openai
from dotenv import load_dotenv, find_dotenv

# 读取本地/项目的环境变量。

# find_dotenv()寻找并定位.env文件的路径
# load_dotenv()读取该.env文件，并将其中的环境变量加载到当前的运行环境中  
# 如果你设置的是全局的环境变量，这行代码则没有任何作用。
_ = load_dotenv(find_dotenv())

# 获取环境变量 OPENAI_API_KEY
openai.api_key = os.environ['OPENAI_API_KEY']
```

将读取`.env`文件的代码封装成函数供每一章节直接调用获取在OpenAI API key。


```python
import os
from dotenv import load_dotenv, find_dotenv
def get_openai_key():
    _ = load_dotenv(find_dotenv())
    return os.environ['OPENAI_API_KEY']

openai.api_key = get_openai_key()
```
